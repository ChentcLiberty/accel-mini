# MiniGEMM Accelerator

8x8 Systolic Array 加速器学习项目

## 项目目标

- 实现 INT8 GEMM 加速器
- 完整验证流程 (cocotb + VCS)
- 性能分析与优化

## 目录结构

accel-mini/
├── docs/ # 设计文档
├── rtl/ # Verilog 代码
├── sim/ # 仿真测试
├── sw/ # Python 工具
├── scripts/ # 自动化脚本
└── results/ # 输出结果
